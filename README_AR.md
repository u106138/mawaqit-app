# تطبيق مواقيت المسجد (أندرويد + أندرويد TV)

مشروع أندرويد جاهز يحمّل صفحة المواقيت (app/src/main/assets/index.html) داخل WebView بملء الشاشة،
ويعمل على الهاتف والتابلت والتلفاز وصناديق الأندرويد.

## ما يضيفه التطبيق على الصفحة
- يظهر في قائمة تطبيقات التلفاز (Leanback) وفي قائمة الهاتف.
- الشاشة تبقى مضاءة (لا قفل شاشة).
- التشغيل التلقائي عند إقلاع الجهاز: خانة "التشغيل التلقائي" في خيارات الصفحة (⚙) تعمل الآن.
- التحديد التلقائي للموقع (بإذن الموقع)، والتخزين المحلي، والأصوات بدون ضغطة أولى.
- أزرار الريموت: OK يفتح الخيارات، Menu يفتح/يغلقها، Back يغلق الخيارات.

## بناء ملف APK — الطريقة الأولى (بدون تثبيت أي برنامج): GitHub
1. أنشئ حساباً مجانياً على github.com ثم مستودعاً جديداً (New repository).
2. ارفع كل محتويات هذا المجلد إلى المستودع (Add file ← Upload files).
3. افتح تبويب Actions ← "Build APK" ← Run workflow.
4. بعد دقائق ينزل ملف mawaqit-apk من صفحة التشغيل (Artifacts). فكّ ضغطه وستجد app-debug.apk.

## الطريقة الثانية: Android Studio
1. ثبّت Android Studio ثم File ← Open واختر هذا المجلد.
2. انتظر مزامنة Gradle ثم Build ← Build APK(s).
3. الملف في app/build/outputs/apk/debug/app-debug.apk

## التثبيت على التلفاز / الصندوق
- انسخ الملف بفلاش USB وافتحه من مدير الملفات (فعّل "مصادر غير معروفة")، أو
- بالأمر: adb connect IP_التلفاز ثم adb install app-debug.apk
- أو أرسله بتطبيق Send Files to TV.

## التشغيل التلقائي عند الإقلاع
1. افتح خيارات التطبيق (OK على الريموت) ← فعّل "التشغيل التلقائي".
2. ستظهر شاشة إذن "العرض فوق التطبيقات الأخرى": فعّله للتطبيق.
3. في بعض الأجهزة افتح إعدادات البطارية/التطبيقات واسمح للتطبيق بالتشغيل التلقائي وبالعمل في الخلفية.

## ملاحظات
- الخطوط تُحمَّل من الإنترنت (Google Fonts)؛ بدون إنترنت تُستخدم خطوط الجهاز. لتضمين الخط داخل التطبيق ضع ملف Cairo
  في assets/fonts وأضف @font-face في index.html.
- درجة الحرارة تحتاج إنترنتاً. بقية الميزات تعمل بدون إنترنت.
- هذا ملف تجريبي (debug) موقّع بمفتاح التطوير ويصلح للتثبيت المباشر. للنشر في المتاجر يلزم توقيع release.
